== Chapter 12: Package the platform so another team can depend on it

Your chapter 11 exercise moved decompression into your codebase with a tested safety contract. That means another team can now run the same ingestion path you run, but only if your public API prevents easy misuse. This chapter turns internal modules into a crate boundary with compile-time guidance.

=== Control extension points with sealed traits

[WARNING]
====
*Public APIs are contracts.* Once a function is public and released, removing it or changing its signature is a breaking change. Code your API as if it will outlive your requirements.
====\n\nYour downstream consumers care about predictable snapshot formats more than domain internals, because integration code and monitoring pipelines depend on stable output contracts from release to release.
