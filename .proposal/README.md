# Proposal Navigation

Use this folder as a planning and discovery hub for both humans and coding agents.

## Entry Points

1. Overview.md: narrative proposal and framing.
2. decisions.md: editorial standing decisions that should not drift.
3. manifest.yaml: machine-readable chapter inventory and status.
4. chapters/: chapter-specific briefs and acceptance criteria.

## Working Rules

1. Keep metadata in sync with chapter files under chapters/.
2. Update chapter status in manifest.yaml when chapter progress changes.
3. Add new editorial constraints to decisions.md before applying them elsewhere.
